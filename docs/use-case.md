# Use Case сипаттамасы

## 1. Жүйе актерлері

Емхананың ақпараттық жүйесінде келесі негізгі актерлер қарастырылады:

- Пациент;
- Дәрігер;
- Тіркеу бөлімінің қызметкері;
- Емхана басшылығы;
- Зертхана қызметкері.

## 3. UC-05 Қабылдауға жазылу

### Актер

Пациент

### Мақсаты

Пациенттің қажетті дәрігерге ыңғайлы уақытта қабылдауға жазылуы.

### Алғы шарт

Пациент жүйеге авторизация арқылы кірген болуы керек.

### Негізгі сценарий

1. Пациент жүйеге кіреді.
2. «Дәрігерге жазылу» бөлімін таңдайды.
3. Қажетті дәрігерді таңдайды.
4. Қабылдау күнін таңдайды.
5. Жүйе дәрігердің бос уақыттарын көрсетеді.
6. Пациент бос уақытты таңдайды.
7. Пациент қабылдауды растайды.
8. Жүйе қабылдау туралы ақпаратты сақтайды.
9. Жүйе пациентке қабылдау туралы хабарлама көрсетеді.

### Альтернативті сценарий

Егер таңдалған уақытта бос орын болмаса:

1. Жүйе бос орын жоқ екенін көрсетеді.
2. Жүйе басқа бос уақыттарды ұсынады.
3. Пациент басқа уақытты таңдайды.
4. Қабылдау тіркеледі.

### Нәтиже

Пациент таңдалған дәрігерге белгіленген уақытқа жазылады.

## 4. UC-08 Медициналық картаны көру

### Актер

Пациент, Дәрігер

### Мақсаты

Пациенттің медициналық ақпаратын көру.

### Негізгі сценарий

1. Пайдаланушы жүйеге кіреді.
2. Медициналық карта бөлімін ашады.
3. Жүйе пациенттің медициналық ақпаратын көрсетеді.
4. Пайдаланушы диагноздар мен дәрігер жазбаларын қарайды.

### Нәтиже

Пациенттің медициналық тарихы жүйеде қолжетімді болады.

## 5. UC-11 Зертханалық нәтижені енгізу

### Актер

Зертхана қызметкері

### Мақсаты

Пациенттің зертханалық талдау нәтижесін жүйеге енгізу.

### Негізгі сценарий

1. Зертхана қызметкері жүйеге кіреді.
2. Пациентті іздейді.
3. Қажетті зертханалық талдауды таңдайды.
4. Талдау нәтижесін енгізеді.
5. Нәтижені сақтайды.
6. Жүйе нәтижені пациенттің медициналық картасына қосады.
7. Жүйе пациентке нәтиже дайын екені туралы хабарлама жібереді.

### Нәтиже

Зертханалық нәтиже пациенттің жеке кабинетінде көрінеді.

## UC-13. Қабылдау туралы хабарлама алу

**Актор:** Пациент

**Мақсаты:** Пациенттің қабылдау уақыты туралы хабарлама алу.

**Сценарий:**
1. Пациент дәрігерге қабылдауға жазылады.
2. Жүйе қабылдау уақытын сақтайды.
3. Жүйе пациентке қабылдау туралы хабарлама жібереді.
4. Пациент хабарламаны алады.
