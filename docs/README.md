# Емхананың ақпараттық жүйесі

## Жоба туралы

Бұл жоба емханадағы негізгі ақпараттық процестерді автоматтандыруға арналған ақпараттық жүйені сипаттайды.

Жүйе пациенттерді тіркеу, дәрігерге қабылдауға жазылу, пациенттің медициналық ақпаратын сақтау, дәрігердің диагнозы мен ұсыныстарын көрсету және зертханалық талдау нәтижелерін басқару мүмкіндіктерін қамтиды.

## Жобаның мақсаты

Жобаның негізгі мақсаты — емхана қызметкерлерінің жұмысын жеңілдету және пациенттерге медициналық қызметтерді ыңғайлы түрде алуға мүмкіндік беретін ақпараттық жүйе құру.

## Жүйенің негізгі функциялары

- Пациентті тіркеу;
- Пациент туралы ақпаратты сақтау;
- Дәрігерлер туралы ақпаратты басқару;
- Дәрігердің бос уақытын көрсету;
- Дәрігерге онлайн қабылдауға жазылу;
- Қабылдауға жазылуды өзгерту немесе жою;
- Пациенттің медициналық картасын жүргізу;
- Диагнозды сақтау және көрсету;
- Дәрігердің ұсыныстарын сақтау;
- Зертханалық талдау нәтижелерін енгізу;
- Пациентке талдау нәтижелері дайын болғаны туралы хабарлама жіберу;
- Пациенттің қабылдау тарихын көру.

## Жүйенің негізгі пайдаланушылары

1. Пациент
2. Дәрігер
3. Тіркеу бөлімінің қызметкері
4. Емхана басшылығы
5. Зертхана қызметкері

## Құжаттар

Жобаның негізгі құжаттары `docs` папкасында орналасқан:

- `requirements.md` — жүйенің талаптары;
- `use-case.md` — Use Case сипаттамасы;
- `diagrams/` — UML диаграммалары.
